# Physics (Measurement & Units)

**World:** `physics` · **bundle_version:** 1

## Terms

| Term | Short definition | Source |
|------|-----------------|--------|
| Amount of substance | The SI base quantity counting elementary entities; its unit is the mole. | BIPM SI Brochure, 9th ed. (2019) — base quantities and units |
| Ampere (A) | SI base unit of electric current, defined by fixing the elementary charge. | BIPM SI Brochure, 9th ed. (2019), §2.3.1; NIST CUU (physics.nist.gov/cuu) |
| Avogadro constant (N_A) | The fixed count of entities per mole that defines the mole. | BIPM SI Brochure, 9th ed. (2019), Table of defining constants; NIST CUU (physics.nist.gov/cuu) |
| Boltzmann constant (k) | The fixed energy-per-temperature constant that defines the kelvin. | BIPM SI Brochure, 9th ed. (2019), Table of defining constants; NIST CUU (physics.nist.gov/cuu) |
| Caesium hyperfine frequency (ΔνCs) | The fixed frequency that defines the second. | BIPM SI Brochure, 9th ed. (2019), Table of defining constants; NIST CUU (physics.nist.gov/cuu) |
| Calibration | Establishing the relation between an instrument's readings and reference values. | JCGM/BIPM VIM 3rd ed. (JCGM 200:2012), §2.39 |
| Candela (cd) | SI base unit of luminous intensity, defined by fixing the luminous efficacy at 540 THz. | BIPM SI Brochure, 9th ed. (2019), §2.3.1; NIST CUU (physics.nist.gov/cuu) |
| Coherent derived unit | A derived unit formed from base units with no numerical factor other than one. | BIPM SI Brochure, 9th ed. (2019), §2.3.4 (coherence) |
| Coulomb (C) | Named derived unit of electric charge: A·s. | BIPM SI Brochure, 9th ed. (2019), Table 4 (named derived units) |
| Electric current | The SI base quantity of charge flow; its unit is the ampere. | BIPM SI Brochure, 9th ed. (2019) — base quantities and units |
| Electron mass (mₑ) | The measured rest mass of the electron. | CODATA 2022 recommended values; NIST CUU (physics.nist.gov/cuu) |
| Elementary charge (e) | The fixed electric charge that defines the ampere. | BIPM SI Brochure, 9th ed. (2019), Table of defining constants; NIST CUU (physics.nist.gov/cuu) |
| Fine-structure constant (α) | The dimensionless constant setting the strength of the electromagnetic interaction. | CODATA 2022 recommended values; NIST CUU (physics.nist.gov/cuu) |
| Hertz (Hz) | Named derived unit of frequency: one cycle per second (s⁻¹). | BIPM SI Brochure, 9th ed. (2019), Table 4 (named derived units) |
| Joule (J) | Named derived unit of energy: N·m = kg·m²·s⁻². | BIPM SI Brochure, 9th ed. (2019), Table 4 (named derived units) |
| Kelvin (K) | SI base unit of thermodynamic temperature, defined by fixing the Boltzmann constant. | BIPM SI Brochure, 9th ed. (2019), §2.3.1; NIST CUU (physics.nist.gov/cuu) |
| Kilogram (kg) | SI base unit of mass, defined by fixing the Planck constant. | BIPM SI Brochure, 9th ed. (2019), §2.3.1; NIST CUU (physics.nist.gov/cuu) |
| Length | The SI base quantity of spatial extent; its unit is the metre. | BIPM SI Brochure, 9th ed. (2019) — base quantities and units |
| Luminous efficacy (K_cd) | The fixed luminous efficacy that defines the candela. | BIPM SI Brochure, 9th ed. (2019), Table of defining constants; NIST CUU (physics.nist.gov/cuu) |
| Luminous intensity | The SI base quantity of perceived light power in a direction; its unit is the candela. | BIPM SI Brochure, 9th ed. (2019) — base quantities and units |
| Mass | The SI base quantity of inertia and gravitation; its unit is the kilogram. | BIPM SI Brochure, 9th ed. (2019) — base quantities and units |
| Measurand | The specific quantity intended to be measured. | JCGM/BIPM VIM 3rd ed. (JCGM 200:2012), §2.3 |
| Measurement uncertainty | The quantified doubt about a measured value — 'uncertainty', not 'error'. | JCGM/BIPM VIM 3rd ed. (JCGM 200:2012), §2.26; GUM (JCGM 100:2008) |
| Metre (m) | SI base unit of length, defined by fixing the speed of light. | BIPM SI Brochure, 9th ed. (2019), §2.3.1; NIST CUU (physics.nist.gov/cuu) |
| Metrological traceability | An unbroken chain of calibrations linking a result to the SI. | JCGM/BIPM VIM 3rd ed. (JCGM 200:2012), §2.41 |
| Mole (mol) | SI base unit of amount of substance, defined by fixing the Avogadro constant. | BIPM SI Brochure, 9th ed. (2019), §2.3.1; NIST CUU (physics.nist.gov/cuu) |
| Newton (N) | Named derived unit of force: kg·m·s⁻². | BIPM SI Brochure, 9th ed. (2019), Table 4 (named derived units) |
| Newtonian constant of gravitation (G) | The measured constant in Newton's law of gravitation — the least precisely known fundamental constant. | CODATA 2022 recommended values; NIST CUU (physics.nist.gov/cuu) |
| Ohm (Ω) | Named derived unit of electrical resistance: V·A⁻¹. | BIPM SI Brochure, 9th ed. (2019), Table 4 (named derived units) |
| Pascal (Pa) | Named derived unit of pressure: N·m⁻² = kg·m⁻¹·s⁻². | BIPM SI Brochure, 9th ed. (2019), Table 4 (named derived units) |
| Planck constant (h) | The fixed quantum of action that defines the kilogram. | BIPM SI Brochure, 9th ed. (2019), Table of defining constants; NIST CUU (physics.nist.gov/cuu) |
| Rydberg constant (R∞) | The constant governing atomic spectral line wavelengths — among the most precisely known constants. | CODATA 2022 recommended values; NIST CUU (physics.nist.gov/cuu) |
| Second (s) | SI base unit of time, realised from the caesium hyperfine frequency. | BIPM SI Brochure, 9th ed. (2019), §2.3.1; NIST CUU (physics.nist.gov/cuu) |
| SI prefix | A decimal multiplier (kilo-, milli-, …) attached to a unit symbol. | BIPM SI Brochure, 9th ed. (2019), §3; 27th CGPM (2022) Resolution 3 (new prefixes) |
| Speed of light in vacuum (c) | The fixed speed of light that defines the metre. | BIPM SI Brochure, 9th ed. (2019), Table of defining constants; NIST CUU (physics.nist.gov/cuu) |
| Tesla (T) | Named derived unit of magnetic flux density: Wb·m⁻² = kg·s⁻²·A⁻¹. | BIPM SI Brochure, 9th ed. (2019), Table 4 (named derived units) |
| Thermodynamic temperature | The SI base quantity of thermal state; its unit is the kelvin. | BIPM SI Brochure, 9th ed. (2019) — base quantities and units |
| Time | The SI base quantity of duration; its unit is the second. | BIPM SI Brochure, 9th ed. (2019) — base quantities and units |
| Vacuum magnetic permeability (μ₀) | The measured magnetic constant of vacuum — no longer exactly 4π × 10⁻⁷ after the 2019 redefinition. | CODATA 2022 recommended values; NIST CUU (physics.nist.gov/cuu) |
| Volt (V) | Named derived unit of electric potential: W·A⁻¹ = J·C⁻¹. | BIPM SI Brochure, 9th ed. (2019), Table 4 (named derived units) |
| Watt (W) | Named derived unit of power: J·s⁻¹ = kg·m²·s⁻³. | BIPM SI Brochure, 9th ed. (2019), Table 4 (named derived units) |
| Weber (Wb) | Named derived unit of magnetic flux: V·s = kg·m²·s⁻²·A⁻¹. | BIPM SI Brochure, 9th ed. (2019), Table 4 (named derived units) |
