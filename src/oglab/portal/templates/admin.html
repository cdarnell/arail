Help & Reference

Common Commands

./oglab start       # launch all services
./oglab stop        # stop all services
./oglab restart     # quick bounce
./oglab update      # check & apply updates
./oglab version     # show component versions
./oglab status      # what's running
./oglab logs        # tail activity log (all)
./oglab logs browser    # browser events only
./oglab logs researcher # research events only

Setup & Configuration

./oglab setup       # first-time setup
./oglab doctor      # validate environment
./oglab reset full  # factory reset (careful!)
./oglab pkb compile # rebuild knowledge base

Environment

All configuration lives in .env at the repo root. Key settings: MODEL_BACKEND, MODEL_NAME, OGLAB_MODE, LAB_ACTIVE_HOURS, LAB_HEAVY_HOURS.

Edit in the terminal tab or directly in your editor.

Updating Components

Run ./oglab update to check all components. Use --check for a dry run. Update a single component with --component open-notebook.

Components are tracked in components.json.

Airgapped vs Hybrid

Click the mode badge in the nav to toggle. Airgapped: zero network calls, fully local. Hybrid: agents can browse the web (with your approval per domain).
