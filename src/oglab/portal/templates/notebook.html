Install Jupyter Lab to enable the Notebook tab

✗ not installed

The Notebook tab embeds Jupyter Lab — the same IDE you'd run locally, but inside the portal so notebooks live next to your PKB and the model router. It ships as part of the lab's core Python deps.

Install

From the repo root, activate the venv and install:

source .venv/bin/activate
pip install -e .

Or bounce ./oglab setup which does this for you: 

./oglab setup

Airgapped / minimal install

If you only want notebooks without the rest of the lab:

pip install jupyterlab

Once installed, restart the lab (./oglab stop && ./oglab start) and this page will flip to the full Jupyter interface automatically.
