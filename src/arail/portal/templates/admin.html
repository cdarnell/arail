Help & Reference

Common Commands

./arail start       # launch all services
./arail stop        # stop all services
./arail restart     # quick bounce
./arail update      # check & apply updates
./arail version     # show component versions
./arail status      # what's running
./arail logs        # tail activity log (all)
./arail logs browser    # browser events only
./arail logs researcher # research events only

Setup & Configuration

./arail setup       # first-time setup
./arail doctor      # validate environment
./arail reset full  # factory reset (careful!)
./arail pkb compile # rebuild knowledge base

Environment

All configuration lives in .env at the repo root. Key settings: MODEL_BACKEND, MODEL_NAME, ARAIL_MODE, LAB_ACTIVE_HOURS, LAB_HEAVY_HOURS.

Edit in the terminal tab or directly in your editor.

Updating Components

Run ./arail update to check all components. Use --check for a dry run. Update a single component with --component open-notebook.

Components are tracked in components.json.

Airgapped vs Hybrid

Click the mode badge in the nav to toggle. Airgapped: zero network calls, fully local. Hybrid: agents can browse the web (with your approval per domain).
