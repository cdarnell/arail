Where the gains come from

Prefetch threading +1.5–2×

Layer N+1 reads from NVMe on a background thread while layer N runs on GPU. Hides compute behind the I/O wall — single-stream latency drops without changing arithmetic.

Batch inference +30–100×

One layer read amortized across many prompts. Disk traffic stays flat as B grows; throughput scales linearly until the GPU saturates. The big win for offline/research workloads with thousands of prompts.

Speculative decoding +2–4×

A small draft model proposes K tokens; the streamed model verifies them in a single forward pass. Accepts ~2–4 tokens per pass on typical prompts — fewer disk reads per emitted token.

Layer-bundle replay cache wins

Hot layers stay resident across prompts; cold layers stream. Replay bundles let identical prefixes skip recomputation. Compounds with batch and spec-decode.

AirLLM — layer streaming on Apple silicon. Each transformer layer is loaded from NVMe into unified memory, executed by MLX kernels in place, then evicted before the next layer streams in. Lets a 70B-class model run on hardware that can't hold the full weights at once.

Architecture — MLX unified-memory streaming

Layers live on NVMe. A rotating window of the current layer is mmap'd into unified memory; MLX kernels read it in place (no PCIe copy — that stage simply doesn't exist on Apple silicon). KV-cache can quantize mid-stream, and the prompt cache reuses prefixes across turns. These are the levers our knobs reach.
