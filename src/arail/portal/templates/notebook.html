The Notebook tab embeds Jupyter Lab — the same IDE you'd run locally, but inside the portal so notebooks live next to your PKB and the model router. It ships as part of the lab's core Python deps.

Install

From the repo root, activate the venv and install:

source .venv/bin/activate
pip install -e .

Or bounce ./arailctl setup which does this for you: 

./arailctl setup

Airgapped / minimal install

If you only want notebooks without the rest of the lab:

pip install jupyterlab

Once installed, restart the lab (./arailctl stop && ./arailctl start) and this page will flip to the full Jupyter interface automatically.

🎧 Generate media with Google NotebookLM

NotebookLM turns your PKB markdown into audio overviews, mind maps, and study guides — a generative layer on top of whatever you've already captured in the lab.

Three-step workflow

1. Pick any file under lab/pkb/ — a research report, a synthesis, a teacher Q&A: 

lab/pkb/agents/research/2026-04-18_*.md
lab/pkb/agents/synthesis/*.md
lab/pkb/teacher/*.md

2. Open notebooklm.google.com and drag the markdown file(s) into a new notebook. Or paste the raw text. You can mix multiple PKB files — NotebookLM will synthesize across them.

3. Ask for an Audio Overview, Mind Map, or Briefing Doc. Save the output back to lab/pkb/media/ so the lab remembers what was produced.

↗ Open NotebookLM

Tip: NotebookLM handles up to 50 sources per notebook. For big PKB sweeps, drop an entire agents/research/ folder — the synthesis across reports is often better than one at a time.
