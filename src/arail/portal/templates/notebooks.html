Workbench

Five ways to work in the lab. Notebooks, reactive notebooks, two NotebookLM alternatives, and opencode for AI-assisted coding — they all share the same filesystem.

📓

Jupyter Lab

classic · exploration · .ipynb

The notebook you already know. Rich widgets, matplotlib, the entire Python data-science ecosystem at your fingertips.

  • Best for interactive data exploration, teaching, and notebooks others can open without setup.
  • Shareable — .ipynb files render natively on GitHub, Kaggle, Colab.
  • Ecosystem — ipywidgets, Plotly, Jupyter AI, and 10,000+ extensions.
  • Dark High Contrast theme pre-selected on first launch.

Marimo

reactive · reproducible · .py

A modern, reactive notebook that runs as plain Python files. Cells re-run when their dependencies change — no stale state, no "did I run this in the right order" confusion.

  • Best for reproducible work, dashboards, and notebooks you'll commit to git.
  • Git-friendly — notebooks are .py, diffs are readable.
  • Reactive — change one cell, dependents re-run automatically.
  • App mode — export any notebook as a standalone web app.

Google NotebookLM

external · audio overviews · mind maps

Upload any lab/pkb/*.md and get back a polished audio overview, mind map, or briefing doc — powered by Google's Gemini-backed NotebookLM. The fastest path from lab notes to media you can actually listen to on a walk.

  • Best for turning research sweeps, teacher Q&As, and agent synthesis into commuter-friendly audio.
  • Audio overviews — two-speaker podcast generated from your sources.
  • Mind maps + briefing docs — structured outputs you can drop back into lab/pkb/media/.
  • Up to 50 sources per notebook — upload an entire agents/research/ folder at once.

Open Notebook

multi-modal · synthesis · RAG

Self-hosted NotebookLM alternative. Ingest PDFs, audio, video, and web pages; chat with your sources; generate multi-speaker podcasts from research piles you haven't read yet.

  • Best for synthesizing knowledge across many documents — "read 40 papers, tell me what they agree on."
  • Multi-modal ingest — PDFs, audio, video, URLs, and plain text.
  • Podcast mode — turn a source pile into a multi-speaker audio briefing.
  • Encrypted at rest with the unified lab passphrase.

opencode

AI coding · browser IDE · Compute Source

AI-powered coding assistant that runs fully in the browser. Edit, generate, and refactor code with the lab's active Compute Source — switch models in the Chat tab and opencode picks it up automatically.

  • Best for editing lab blueprints, agent scripts, and experiment code without leaving the lab.
  • Compute Source aware — inherits your active provider (My Machine, Claude, custom endpoint).
  • Local-first — binds 127.0.0.1:4096 only, not reachable from outside.
  • MIT licence — open source, auditable, forkable.
