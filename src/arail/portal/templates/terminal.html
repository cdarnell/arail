The Terminal tab embeds a real local shell via ttyd — an open-source WebSocket terminal (<1 MB, zero config). Install it with one command for your platform, then run ./arailctl start again:

macOS

brew install ttyd

Linux

sudo apt install ttyd           # Debian / Ubuntu / WSL
sudo dnf install ttyd           # Fedora
sudo pacman -S ttyd             # Arch
sudo emerge -av www-apps/ttyd   # Gentoo

Build from source

git clone https://github.com/tsl0922/ttyd
cd ttyd && mkdir build && cd build && cmake .. && make && sudo make install

Once installed, restart the lab and this page will flip to the full terminal automatically.
