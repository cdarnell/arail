Gemma Terms of Use
===================

Authoritative full text:  https://ai.google.dev/gemma/terms
(This file is the bundled in-repo copy. Before any PUBLIC distribution of a
build whose default model is the Gemma-based `qkz-project-aware-2b`, paste the
VERBATIM current Gemma Terms of Use from the URL above into this file — it is
the legally operative text. The summary below records the obligations ARAIL
must satisfy and the required notice.)

Required distribution notice (verbatim, Gemma Terms §3.1(4))
------------------------------------------------------------
    "Gemma is provided under and subject to the Gemma Terms of Use found at
     ai.google.dev/gemma/terms"

This notice accompanies every non-hosted distribution (it is reproduced in the
repo NOTICE file and is shown in-app where the model is surfaced).

Distribution obligations (Gemma Terms §3.1) that ARAIL satisfies
----------------------------------------------------------------
  1. Provide recipients a copy of the Gemma Terms of Use (this file + the URL).
  2. Include the required notice above (NOTICE + in-app).
  3. Mark any modified files / model derivatives with prominent notices of the
     modifications made (the persona wrap in models/ai-eng/Modelfile.gemma
     states it is built with Gemma; its base + the modification are attributed
     in NOTICE).
  4. Pass through the use restrictions of the Gemma Prohibited Use Policy
     (bundled at licenses/GEMMA-PROHIBITED-USE-POLICY.txt), incorporated by
     reference into the Terms.

Naming: the Gemma Terms do NOT require the distributed model name to contain
"Gemma" (unlike the Llama 3.2 Community License's "begin with Llama" rule).
Confirmed from ai.google.dev/gemma/terms — so `qkz-project-aware-2b` needs no
rename. (Attribution is still required via the notice + NOTICE, above.)
