# Power Consumption Logic for LLM Inference (n8n)

## Overview
This document describes the n8n logic to calculate the power cost of an LLM inference task. It multiplies the task duration by the current wattage (from Prometheus, Linkerd-optimized Metrics Spec), then compares the result to a standard $0.03-per-1k-tokens API cost.

---

## n8n Workflow Logic (Pseudocode)

1. **Input:**
   - `inference_duration_seconds` (float): Duration of LLM inference in seconds
   - `current_wattage` (float): Current power draw in watts (from Prometheus query)
   - `tokens_generated` (int): Number of tokens generated by the LLM

2. **Calculate Power Consumption (Wh):**
   - `power_consumed_wh = (current_wattage * inference_duration_seconds) / 3600`

3. **Estimate Power Cost:**
   - `power_cost_usd = power_consumed_wh * [local electricity rate, e.g., $0.12/kWh]`

4. **Calculate API Cost:**
   - `api_cost_usd = (tokens_generated / 1000) * 0.03`

5. **Compare Costs:**
   - If `power_cost_usd > api_cost_usd`, log or alert: "Local inference is more expensive than API."
   - Else, log: "Local inference is cheaper than API."

---

## Example n8n Node Sequence

1. **HTTP Request Node** (Prometheus):
   - Query: `sum(rate(container_cpu_usage_seconds_total{container="llm-inference"}[1m])) * 65`  
     (Assuming 65W per CPU core, adjust as needed)
2. **Set Node:**
   - Set `inference_duration_seconds` and `tokens_generated` from previous steps
3. **Function Node:**
   - Calculate `power_consumed_wh`, `power_cost_usd`, `api_cost_usd`, and comparison

---

## Linkerd-Optimized Metrics Spec Reference
- Use Prometheus queries filtered by Linkerd labels (e.g., `namespace`, `pod`, `service`)
- Example metric: `container_cpu_usage_seconds_total{container="llm-inference",namespace="ai-lab"}`

---

## Example Function Node (JavaScript)
```js
const duration = items[0].json.inference_duration_seconds;
const wattage = items[0].json.current_wattage;
const tokens = items[0].json.tokens_generated;
const electricity_rate = 0.12; // USD per kWh

const power_consumed_wh = (wattage * duration) / 3600;
const power_cost_usd = (power_consumed_wh / 1000) * electricity_rate;
const api_cost_usd = (tokens / 1000) * 0.03;

return [{
  json: {
    power_consumed_wh,
    power_cost_usd,
    api_cost_usd,
    cheaper_local: power_cost_usd < api_cost_usd
  }
}];
```

---

## Notes
- Adjust `electricity_rate` for your local cost.
- Prometheus query and wattage multiplier may need tuning for your hardware.
- For Linkerd, always filter metrics by `namespace` and `service` for accuracy.
