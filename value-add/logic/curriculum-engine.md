# Curriculum Engine Logic

## Teacher Agent (OpenCode.ai)
- Scans the Knowledge Yard (user uploads, docs, workflows)
- Suggests new "Classes" or workflows based on detected topics, gaps, or user goals
- Explains why a workflow is recommended
- Maps suggestions to user personas and learning paths

### Example Flow
1. User uploads a new dataset or workflow
2. Teacher agent analyzes content for new topics or skills
3. Suggests a new "Class" (workflow) in the Nucleus Academy
4. Provides rationale and learning objectives

---

## Why This Matters
- Makes onboarding and workflow discovery human and accessible
- Ensures users always have actionable next steps
