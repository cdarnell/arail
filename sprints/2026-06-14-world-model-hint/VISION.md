# Vision: World model_hint — a World declares its ideal brain

**Date:** 2026-06-15
**Product:** arail
**Wedge size:** one sprint

## User

Name: a friend the owner gave a cloned ARAIL lab to — call her the Physics tinkerer.
She has the lab running on a 16 GB Apple-silicon laptop. The owner shipped her a
DaC-built **Physics World** bundle. She mounts it. The mount works exactly as
designed: the lab re-themes, the knowledge base fills with physics terms, the
agents and palette flip, capabilities light up. The lab now *looks and knows*
physics.

Then she asks her first real question — "walk me through deriving the
relativistic Doppler shift" — and the answer comes back confused, hand-wavy,
arithmetic wrong. Because the brain answering is still `llama-ai-eng`
(Llama-3.2-1B). The World flipped everything *except the one thing that
generates the words she reads.*

This is concrete and it is the moment the value leaks: the mount promised "this
lab is now a physics lab" and the inference contradicts it on the first turn.

## Problem

The DaC→ARAIL mount can flip knowledge, theme, agents, capabilities, and colors,
but **not the inference model**. A 1B default is below the floor for technical
domains (physics, math, deeper code). So the lab's *competence* does not move
when its *identity* moves. The user experiences a polished, themed, knowledgeable
shell wrapped around a brain that can't do the domain — which reads as broken,
not weak.

Two distinct failures, one root:
1. **Mounted-World gap:** the World knows what brain it wants and has no way to
   say so. ARAIL has no field to read.
2. **No-World floor:** even with nothing mounted, the everyday default is a 1B,
   so *every* domain infers worse than it has to on hardware that can run a 2B.

The requested feature ("`model_hint` field + Gemma default") is a solution. The
problem is: **the lab's competence is decoupled from its declared identity, and
the unmounted floor is set too low.**

## Win condition

Falsifiable, witnessable, pre-committed thresholds:

1. **Mounted, hint present, model available locally:** mount a Physics World
   declaring `model_hint` for a physics-capable model already pulled → ARAIL
   surfaces a one-tap "This World recommends <model> — switch?" prompt via the
   existing model picker, and after one tap the next answer is generated by the
   recommended model. Verified by: the model picker shows the hinted model
   active, and the relativistic-Doppler answer is materially better than the 1B
   baseline (owner judges side-by-side; this is a judgment call, witnessed, not
   a benchmark — acceptable for a wedge).
2. **Mounted, hint present, model NOT installed:** the prompt offers the
   consent-gated download (size shown, e.g. "~3.3 GB"). Declining leaves the lab
   fully working on the current model. **Mount never blocks on this.**
3. **No World mounted / no hint declared:** the everyday default is the ~2B
   `qkz-project-aware-2b` generalist, not the 1B — verified by a fresh setup
   landing on the 2B and answering a physics question better than the 1B did.
4. **Hint absent / malformed / names an unknown model:** lab behaves exactly as
   today (current model unchanged, no error surfaced to user). Graceful, silent,
   never a broken lab.

Pre-committed: if condition 1 cannot be demonstrated end-to-end on the owner's
own machine in the sprint, the wedge has not shipped.

## Wedge

**v1 = READ + SUGGEST + default-floor swap. One sprint.**

In scope:
- ARAIL reads a new **OPTIONAL, seal-exempt** `model_hint` from the bundle, via
  the *exact* precedent already in `world_mount.py`: a best-effort resolver that
  writes a sidecar (mirror of `_resolve_and_write_capabilities` /
  `world-capabilities.json`), absent→none, malformed→none + logged, **never
  blocks mount**. ARAIL READS; DaC DECLARES. ARAIL does not import DaC.
- On mount, if a hint resolves to a catalog model, surface a **one-tap suggestion
  banner** through the existing chat model picker. Installed → "switch?".
  Not installed → consent-gated download (size shown), then switch.
- **No silent auto-download. No silent auto-switch.** Heavy, consent-gated, and
  reversible — the user stays in control of what occupies their disk and RAM.
- Swap the no-World default from `llama-ai-eng` (1B) to `qkz-project-aware-2b`
  (~2B Gemma generalist) in the catalog + `scripts/setup.sh`.

Explicitly ROADMAP, not this sprint:
- Auto-load-on-mount (silent) — gated behind evidence that download friction is
  acceptable.
- Per-World model *pinning* / multi-model session management.
- AeroLLM frontier-lane hints (the deep/operator-configured lane).

Justification: the suggest-don't-auto-load wedge tests the entire hypothesis
("a World can declare its brain and it improves the answer") at the cost of one
banner + one resolver + one default swap, all on the owner's own machine with no
cloud account. Auto-load adds download-orchestration risk that the wedge doesn't
need to prove value. Pin/multi-model is a management feature, not a value test.

## Disconfirming evidence

Pre-committed kill/shelve signals:

1. **Download friction kills it:** if pulling the hinted model on mount is so
   slow/heavy that the owner (and first friend) decline it both times and just
   keep the default → the "World declares its brain" link is rejected; the
   model_hint field is shelved and only the 2B default ships.
2. **2B still too weak to matter:** if `qkz-project-aware-2b` on the physics
   question is not visibly better than the 1B in the owner's side-by-side → the
   floor swap is theater; defer until the Gemma model is actually stronger.
3. **Users want to choose regardless of World:** if the owner finds himself
   ignoring the hint and picking manually anyway → the hint is noise; the value
   is in the picker, not the declaration. Shelve `model_hint`.
4. **License friction blocks ship:** see risk below — if "Built with Gemma"
   disclosure can't be satisfied cleanly for the default, the 2B default cannot
   ship and the wedge collapses to mounted-hint-only.

## Displacement

- **Manual model-picking as the only path:** the picker stays, but the World now
  gets a voice in it. This is additive, but it shifts the mental model from
  "user owns model choice" to "World can recommend" — a deliberate trade.
- **One-model-for-everything:** the simplicity of a single default is displaced
  by a 2B floor plus per-World hints. More models on disk, more state.
- **Cross-product:** a sprint on arail is a sprint not on aerollm's frontier
  lane or distill. Specifically this pulls owner attention away from the
  `2026-05-20-aerollm-72b-lift` / KV-budget line of work. Not "nothing" — it is
  one of three products' worth of weekly attention.

## Risks & coordination (not hand-waves)

- **CROSS-REPO (blocking dependency):** the `model_hint` DaC-side field AND the
  `qkz-project-aware-2b` model artifact live in the **parallel `qukaizen-dac`
  session**. This sprint designs and builds only the **ARAIL-side contract +
  behavior**. It must define the wire format of `model_hint` precisely (a
  portable file field, Standing Rule 3 boundary) so the DaC session can emit it,
  and it must degrade gracefully if neither the field nor the model exists yet.
  **Recommendation: ARAIL ships READ-side + 2B default behind the model
  actually existing; coordinate the artifact handoff explicitly in SPRINT.md.**
- **LICENSE (real constraint, flag to architect):** the repo carries a strict
  Llama disclosure exception ("Built with Llama" + bundled license for
  `llama-ai-eng`). A Gemma default introduces a **parallel Gemma Terms
  disclosure ("Built with Gemma")**. This is a hard gate on shipping the 2B
  default — the disclosure surface (NOTICE, licenses/, in-app attribution) must
  be extended before the swap lands. The architect must treat this as a
  ship-blocker, not a footnote.

## Recommended next step

**PROCEED to /architect** with this wedge as the spec — with two named gates the
architect must design around: (1) the `qukaizen-dac` cross-repo handoff (define
the `model_hint` portable-file contract precisely; degrade gracefully if absent),
and (2) the **Gemma Terms disclosure** as a ship-blocker on the default swap.

The contract design + the mounted-hint READ behavior can proceed now regardless
of DaC timing; the default-floor swap ships only once both the Gemma model
artifact and its disclosure exist. If neither lands in-sprint, the fallback
shippable is mounted-hint-READ-only against a stub bundle — still a real test of
the hypothesis.
