## Summary
ARAIL's docs are broadly well-maintained (CHANGELOG, tier-selection.md, NOTICE, the Llama/Gemma disclosure chain, and the arailctl CLI surface are accurate), but drift accumulated because CLAUDE.md and several docs froze before the June-July Worlds/DaC/lab-persistence work landed. The biggest issue is CLAUDE.md's self-reported state (114 commits, latest 2026-04-28) vs reality (644 commits, latest 2026-07-22), cascading into a stale five-surfaces list that omits Worlds and DaC. Llama disclosure obligations are fully honored (README + catalog + Modelfile.default persona prompt all say Built with Llama, NOTICE bundles license+AUP, name begins with Llama); the Gemma gate is a correctly-dormant placeholder. Tier naming is inconsistent: legacy min/max and a retired three-way min/med/max survive in AGENTS.md, README, BLUEPRINTS.md, REPOSITORY_LAYOUT.md, .env.example, and setup.sh comments. Two concrete contradictions with code: (1) README/CLAUDE/INSTALL say Docs is maximus-only, but code puts Docs in the minimalist tier set; (2) .env.example advertises the default model as a 3B Opus-4.7-derived Nucleus model that never shipped - the real default is llama-ai-eng (Llama-3.2-1B). build-and-finetune-plan.md and maximus.plan.md are near-identical duplicate plans, and standards-compliance.md's file:line citations are ~2,500 lines stale.
